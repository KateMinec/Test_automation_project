# Проект по автоматизации тестирования интернет-магазина «Комус»

Проект представляет собой автоматизированный тестовый сценарий для проверки процесса авторизации, поиска по каталогу, фильтрации, сортировки, выбора товара и перехода к оформлению заказа в разделе «Холодильники» на сайте интернет-магазина Комус.

Скрипт переведен на фреймворк **PyTest** и структурирован с использованием паттерна проектирования **POM (Page Object Model)**.

## 🛠 Технологический стек
* **Язык программирования:** Python 3.9+
* **Фреймворк тестирования:** PyTest
* **Инструмент автоматизации:** Selenium WebDriver
* **Архитектурный паттерн:** Page Object Model (POM)

## 📁 Структура проекта

Comus_project:
  pages/                  # Каталог с классами страниц (Page Objects)
    base_page.py          # Базовый класс с общими методами (ожидания, скроллинг)
    login_page.py         # Класс страницы авторизации
    catalog_page.py       # Класс каталога, фильтрации и выбора холодильников
    cart_page.py          # Класс страницы корзины и перехода к оформлению
  tests/                  # Каталог с тестовыми сценариями
    test_comus.py         # Основной тест сквозного процесса (End-to-End)
    conftest.py              # Файл конфигурации PyTest (фикстуры браузера)
 screenshots/             # Папка для сохранения финальных скриншотов
 README.md                # Документация проекта


## 📝 Описание тестового сценария (Workflow)
1. **Авторизация:** Открытие главной страницы сайта, ввод учетных данных пользователя и успешный вход в личный кабинет.
2. **Навигация:** Переход по цепочке категорий: *Каталог* → *Бытовая техника* → *Крупная бытовая техника* → *Холодильники*.
3. **Фильтрация:** Изменение ценового диапазона с помощью ползунка (Slider) и выбор типа разморозки *No Frost*.
4. **Стабильность (Intro.js):** Автоматическая обработка и закрытие всплывающей пленки-подсказки сайта (в блоке `try...except`), если она появляется на экране.
5. **Сортировка:** Установка сортировки товаров «Сначала дешевые» и принятие соглашения об использовании cookies.
6. **Выбор товара:** Парсинг названия и цены второго холодильника в списке и добавление его в корзину.
7. **Проверка в корзине:** Переход в корзину (в текущей вкладке браузера) и сверка названия товара, его цены и финальной стоимости заказа через `assert`.
8. **Оформление заказа:** Нажатие на кнопку «Оформить заказ» и автоматическое создание финального подтверждающего скриншота в папке `screen/` с функцией перезаписи старого файла (`checkout_page_latest.png`).

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd Comus_project
```

### 2. Установка необходимых библиотек
Убедитесь, что у вас активировано виртуальное окружение, и выполните:
```bash
pip install -r requirements.txt
```
*(Или вручную: `pip install selenium pytest`)*

### 3. Запуск автотеста
Для запуска теста с подробным выводом логов (принтов) в консоль выполните следующую команду из папки `tests`:
```bash
python -m pytest -s -v test_comus.py
```

## 📸 Скриншоты результатов
После успешного завершения теста в корне проекта автоматически создается/обновляется папка `screen/`. Внутри неё сохраняется актуальный снимок экрана со страницы оформления заказа. При повторном прогоне старый скриншот перезаписывается новым для экономии места.
